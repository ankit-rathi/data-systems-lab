# Agent Work Contract

Before an agent touches a system, specify:

| Field | Question |
|---|---|
| Goal | What outcome is actually required? |
| Context | Which facts, files and measurements may the agent trust? |
| Constraints | What must not change? |
| Tools | Which operations are available? |
| Permissions | What is the maximum allowed action? |
| Success criteria | What observable evidence means success? |
| Failure conditions | When must the agent stop? |
| Evidence required | What must be recorded for review? |
| Escalation policy | What requires human approval? |

A prompt is not a work contract. A work contract defines the boundary around the prompt.
