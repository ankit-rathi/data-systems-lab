# DATA-1051 — Work Simulation

Treat this as an engineering ticket, not a guided answer.

## Learner path
1. Read `ticket.md`.
2. Inspect the fixture and implementation.
3. Write at least two plausible hypotheses.
4. Run the baseline checks.
5. Make the smallest defensible change.
6. Add a regression test.
7. Record evidence in `evidence.md`.
8. Write a short PR-style summary and production prevention idea.

## Boundary
This is deterministic teaching material. It models a failure mechanism; it is not a production service or performance benchmark.
