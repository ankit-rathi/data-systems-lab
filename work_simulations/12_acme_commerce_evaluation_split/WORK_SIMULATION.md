# Work Simulation Contract — 1145

## Scenario

DATA-1145 — Model review cannot reproduce the reported test score

## Pairing

Notebook **33 — Train / validation / test**.

## Learner sequence

1. Read the ticket only.
2. Inspect the fixture and existing implementation.
3. Write at least two plausible hypotheses.
4. Run the supplied tests before changing code.
5. Make the smallest defensible change.
6. Add evidence and a regression/guardrail test.
7. Explain both technical and business impact.
8. Describe the production follow-up.

## Evidence rule

Do not write the diagnosis before you have evidence.
