# Reference solution — Notebook 37

## What the exercise is testing

Find where an LLM system should reject bad context or policy conflicts.

## Reference approach

Stale context belongs to context freshness/validation; policy conflicts belong to policy enforcement. The agent should not be allowed to resolve either merely because it produced fluent output; independent checks must gate action.

## What a strong submission should contain

- **Prediction:** what you expected before running the experiment.
- **Evidence:** the measurement, output, query result or trace that supports your conclusion.
- **Failure/edge case:** one case that could have disproved your explanation.
- **Diagnosis:** mechanism → evidence → conclusion.
- **Production boundary:** what this notebook proves, what it does not prove, and what you would verify in a real system.
