# Engineering Portfolio Template

Copy this directory when you want to keep a personal evidence portfolio outside the course repository.

The portfolio is organized around engineering evidence, not notebook completion:

```text
requirements → architecture → contracts → experiments → incidents
→ agent work → decisions → evals → production defense
```

## Minimum evidence record

Every portfolio item should answer:

1. What problem or requirement were you given?
2. What did you predict or hypothesize?
3. What evidence did you inspect?
4. What changed?
5. How did you verify it independently?
6. What failed or remained uncertain?
7. What decision did you make?
8. What would you monitor or revisit in production?

Do not include credentials, private prompts, customer data, or proprietary material.
