# Notebook Template

Copy this structure when creating a new notebook. The actual notebook should use Markdown and code cells following this order.

1. Title + one-sentence promise
2. **Sketch note**
3. Why this concept exists
4. Learning objectives
5. Prerequisites
6. Mental model
7. Predict before running
8. Smallest useful implementation
9. Measure
10. Break deliberately
11. Diagnose
12. Improve
13. Production implications
14. Explain it in 90 seconds
15. Challenge
16. Takeaways
